# AEGIS — собственный язык и нативная IDE

Реализация на x86-64 ассемблере (FASM), Win32, без CRT и браузерной оболочки.
Компилятор генерирует машинный код и самостоятельный Windows x64 EXE.
Виртуальная машина для выполнения программ не требуется.

## Сборка и запуск

```powershell
.\build.cmd
.\aegis.exe                    # графическая IDE
.\aegisc.exe build examples\factorial.ae factorial.exe
.\factorial.exe
.\build.cmd test               # сборка и интеграционные проверки
```

FASM уже находится в `tools/`. Python нужен только для тестов.
`aegis.exe` — GUI-приложение; `aegisc.exe` — та же реализация с консольной
подсистемой, чтобы PowerShell ожидал завершения CLI-команд.
Среда выполнения AEGIS для готового EXE не нужна: используются только функции Windows.

## Проверенная функциональность компилятора

- `fn main()` и именованные функции с 0–4 параметрами; вызовы вперёд и рекурсия.
- 64-битные целые, десятичные и шестнадцатеричные литералы, локальные переменные.
- `let`, присваивание, `return`, `if / else if / else`, `while`, блоки.
- `+ - * / %`, сравнения `== != < > <= >=`, унарные `+ - !`, скобки.
- `printi(value)` с переводом строки, `printc(byte)`, `exit(code)`.
- Комментарии `//` и `/* */`, UTF-8 BOM, необязательные точки с запятой.
- Ошибки со строкой и столбцом; ограничения размера и глубины разбора.
- Формирование PE32+, корректные импорты и вызовы по соглашению Win64.
- Запись через временный файл в каталоге назначения: ошибочная запись
  или отказ замены не удаляют существующий файл.

Точные правила и ограничения описаны в [LANGUAGE.md](LANGUAGE.md).
Тесты запускают скомпилированные EXE и проверяют их вывод и коды завершения.

## IDE: реализованная основа, требует продолжения проверки

Вместо прежней заглушки реализовано окно AEGIS Studio:

- тёмная палитра, моноширинный редактор RichEdit, панель Output и строка состояния;
- New / Open / Save / Save As, UTF-8, предупреждение о несохранённых изменениях;
- Ctrl+N, Ctrl+O, Ctrl+S, Ctrl+Shift+S, F6 — сборка, F5 — сборка и запуск;
- компиляция текущего текста редактора в `<путь исходника>.exe`;
- отдельный процесс программы, асинхронный захват stdout/stderr, Stop и код завершения;
- ограничение захватываемого вывода 1 МиБ и очистка временной памяти компилятора;
- диалоги без добавления файлов в системный список Recent.

Код IDE собирается. Полная проверка открытия, редактирования, сохранения,
перерисовки и запуска через интерфейс **ещё не завершена**: проверка управления
окном была остановлена пользователем. CLI-тесты не подменяют эту проверку.

Это начало IDE, а не завершённая профессиональная среда: пока один документ,
нет вкладок, дерева проекта, подсветки синтаксиса, поиска, автодополнения,
отладчика и настроек. Текущая версия рассчитана на Windows 10/11 x64;
масштабирование на разных DPI ещё нужно проверить.

## Экспериментальное кодирование исходников

```powershell
.\aegisc.exe enc program.ae program.aeg -k D:\keys\project.bin -c 0xABC
.\aegisc.exe build program.aeg program.exe -k D:\keys\project.bin -c 0xABC
.\aegisc.exe dec program.aeg restored.ae -k D:\keys\project.bin -c 0xABC
.\aegisc.exe test
```

Ключ нужно предоставить самостоятельно; не храните рабочий ключ вместе с проектом.
Сборка `.aeg` декодирует исходник в памяти, компилирует его и затирает
декодированный буфер и прочитанный ключ после операции.
Команда `dec` специально создаёт обычный читаемый файл.

Сохранён унаследованный формат `AEG0`: 1024 кодовых знака, 4096 кодов диалекта,
ChaCha20, SHA-256 и собственный KDF. Проверены roundtrip, отказ при неверном
ключе/диалекте и обнаружение изменения полезной нагрузки.
Формат **экспериментальный, криптографический аудит не проведён**.
В текущей реализации нет свежего случайного nonce на каждый файл; это нельзя
считать готовой криптографической защитой. Проверка roundtrip не доказывает стойкость.

Интеграции внешнего ключа и `.aeg` в графический редактор пока нет.
Исходники `lz.asm` и `cursed.asm` сохранены для дальнейшей разработки,
но LZ и текстовое отображение глифами не включены. `render` / `u`
явно сообщают о недоступности. Защита готового EXE и опциональные протекторы
не реализованы; старые документы описывают замысел, а не готовые возможности.

## Структура

```text
src/aegis.asm          вход, импорты WinAPI, общая сборка
src/cli.asm            команды CLI и selftest
src/core/compiler.asm  лексер, разбор, нативный кодоген, PE
src/core/heap.asm      память, захват диагностики, файловые операции
src/core/wcall.asm     вызовы WinAPI и выравнивание стека
src/core/crypto.asm    унаследованное криптоядро
src/core/codec0.asm    экспериментальный AEG0
src/core/lz.asm        незавершённый модуль ссылочного сжатия
src/core/cursed.asm    незавершённое отображение глифами
src/ide/ide.asm        нативное окно редактора, файлы, Build / Run
src/data.asm           общие данные
examples/factorial.ae  пример функций и циклов
tools/test.py          интеграционные проверки
```
