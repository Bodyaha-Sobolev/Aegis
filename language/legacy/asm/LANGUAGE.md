# AEGIS: текущая реализация языка

Это описание работающего подмножества, которое будет расширяться.

## Программа

```text
fn add(a, b) {
    return a + b;
}

fn main() {
    let answer = add(20, 22);
    printi(answer);
    return 0;
}
```

Обязательна ровно одна функция `main` без параметров. Порядок функций не важен.
У каждой функции не более четырёх параметров. Все аргументы и результаты —
64-битные целые. Падение через конец функции возвращает 0.
Имена состоят из ASCII-букв, цифр и `_`, начинаются с буквы или `_`,
регистр учитывается. Unicode разрешён в комментариях.

## Выражения

Литералы: `42`, `0x2A`, `0X2a`. Хранятся 64 бита; отрицательное число задаётся
унарным минусом. Литерал шире 64 бит отвергается.
Арифметические операции работают с младшими 64 битами, переполнение не проверяется.
Деление и остаток — знаковые; частное округляется к нулю.
Деление на ноль и переполнение знакового деления пока дают аппаратное исключение.

Приоритет: скобки/вызовы; унарные `+ - !`; `* / %`; `+ -`; все сравнения.
Бинарные операции одного приоритета выполняются слева направо.
Сравнения и `!` возвращают 0 или 1. Ноль в условии означает false,
любое другое значение — true. Логические `&&` и `||` пока отсутствуют.

Аргументы вызова вычисляются слева направо. Поддерживаются вложенные вызовы
и рекурсия. Несовпадение числа параметров обнаруживается при сборке.

## Переменные и управление

```text
let i = 0;
while (i < 10) {
    if (i % 2 == 0) {
        printi(i);
    } else {
        printc(46);
    }
    i = i + 1;
}
```

`let` требует инициализатор; переменная доступна после объявления до конца блока.
Использование до объявления и повтор имени среди активных переменных запрещены.
Затенение активной переменной пока не поддерживается. Переменные из завершённых
блоков недоступны. `return expression` выходит из функции.
Точки с запятой после простых инструкций необязательны.

`printi(expression)`, `printc(expression)`, `exit(expression)` — встроенные
инструкции, а не значения выражений. `printi` печатает знаковое число и LF;
`printc` выводит младший байт; `exit` завершает процесс с младшими 32 битами кода.
Возвращаемое значение `main` также становится кодом завершения процесса.

Пока нет строк, массивов, типов, указателей, доступа к памяти, внешних вызовов,
модулей, структур, `break`/`continue`. Добавление этих возможностей — следующий
этап развития языка; ориентир остаётся на нативный низкоуровневый доступ.

## Ограничения прототипа

- Исходный текст — до 1 МиБ; до 32767 токенов плюс конец файла.
- До 256 функций, 256 локальных слотов на функцию и 4096 мест вызова.
- До 64 КиБ машинного кода вместе с небольшими служебными процедурами.
- Глубина разбора ограничена счётчиком 128; вложенные выражения используют
  несколько уровней счётчика на одну пару скобок.
- Результат — Windows x64 PE32+, размер текущего контейнера фиксирован: 67584 байта.
- Файловая запись пока использует Win32 MAX_PATH (полный путь короче 260 символов).
- В EXE пока нет отладочных символов и таблиц unwind, оптимизация не реализована.

Компилятор прекращает сборку с диагностикой при превышении своих лимитов.
Синтаксические и семантические ошибки выводятся как `ERROR строка:столбец: причина`.
Столбец считается по байтам UTF-8. Успешный CLI возвращает 0, ошибка — 2.
