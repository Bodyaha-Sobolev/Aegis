# Измерения Aegis

Измерения не являются обещанием превосходства над другими языками. Они
фиксируют воспроизводимую базовую точку для следующих изменений.

Команда компилятора:

```powershell
cargo run --locked --release --example bench -p aegis-lang
py tools/bench_array_growth.py --compiler current=target/release/aegis-cli.exe
```

На машине разработки 28 октября 2026 года (`Windows 11`, `AMD64`) 1000
компиляций `examples/factorial.ae` заняли **97.84 мкс на компиляцию**.
После перехода к 0.2.26/0.2.27 тот же benchmark показал **86.02 мкс на
компиляцию** в release-профиле; это отдельный запуск и не обещание постоянного
ускорения на другой машине.
Нативный тест роста динамического массива проверяет контрольную сумму и
измеряет полный запуск отдельного процесса, включая запуск Windows,
выделение, индексацию и освобождение; компиляция в это время не входит.
Сырые выборки, SHA-256 исходников и EXE сохранены в
`artifacts/benchmark-022.json` и намеренно не входят в релиз как
машинно-зависимый результат.

Перед сравнением нужно использовать одинаковые размеры, число прогонов,
режим сборки и исключать первый запуск как прогрев. Любое ускорение должно
сохранять вывод, границы массивов, освобождение памяти и остальные native
проверки.
