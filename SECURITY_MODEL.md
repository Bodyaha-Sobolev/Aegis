# Модель безопасности Aegis Studio

Этот документ описывает границы текущего продукта и контракт для будущих
интеграций AI/MCP. Он не утверждает, что IDE уже умеет управлять всем ПК.

## Действующие границы

- Компилятор принимает исходный текст и создаёт отдельный Windows x64 EXE.
- Инспектор PE/DLL/SYS читает переданный файл как снимок. Он не загружает DLL,
  не запускает код и не подключается к произвольному процессу.
- Команда запуска IDE создаёт только собственный дочерний процесс. Остановка
  относится к этому процессу и не ищет чужие PID.
- FFI помечен `unsafe extern`; библиотека загружается только при фактическом
  вызове и только по проверенным правилам пути. FFI не является sandbox.
- Исходный код и защищённые файлы ограничены размерами, а операции памяти и
  native-код имеют проверяемые лимиты.

## Контракт разрешений

Каждое действие внешнего AI/MCP-адаптера должно иметь запись:

```text
request_id, timestamp, actor, capability, target, parameters_hash,
decision, reason, result, duration_ms
```

Минимальные capability: `read_workspace`, `write_workspace`, `run_owned_child`,
`inspect_file`, `network_request`, `load_ffi`. Разрешение действует только для
конкретного запроса и цели; широкое «полный доступ» не должно выдаваться
молча. Отказ, отмена и ошибка также записываются. Секреты и содержимое файлов
в журнал не попадают — только хеш параметров и ограниченное описание цели.

## Небезопасные действия

Запуск произвольного PID, чтение или запись чужой памяти, инъекция, скрытая
слежка, установка драйвера и изменение системных политик не являются текущими
возможностями. Если такие инструменты появятся для легитимной отладки, они
потребуют отдельного явного разрешения, видимого подтверждения цели,
ограничения времени и неизменяемой записи аудита.

## Проверка изменений

Изменение границ capability требует теста отказа, теста отмены, проверки
журнала и отдельной GUI-проверки. Сравнение производительности не может
отменять эти ограничения. Новая интеграция сначала должна работать в режиме
просмотра и симуляции, а запись/запуск включается отдельным разрешением.
